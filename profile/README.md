## Cubase Pro Highlights

- **Key Editor:** Cubase Pro key editor shows MIDI notes so you can fix a melody after you play it.
- **MixConsole:** Cubase Pro mixconsole is the mixing desk for levels, pans, and a few inserts on a small song.
- **VariAudio:** Cubase Pro variaudio lets you adjust pitch on a vocal or a solo line you recorded at home.
- **Chord Track:** Cubase Pro chord track names the chords so a study piece stays harmonically clear.
- **Control Room:** Cubase Pro control room separates what you hear in headphones from the mix you will render.

---

## What Is Cubase Pro

Cubase Pro is a detailed music workspace that still fits home study and short pieces. Cubase Pro key editor is where written notes get cleaned up. Cubase Pro mixconsole is where those notes and recordings find a balance you can stand to hear in a small room. You can learn both on a laptop without treating every exercise like a large production.

Cubase Pro chord track helps when a class asks you to follow a progression. Cubase Pro variaudio helps when a sung line is close but not quite in tune, and you want a careful correction rather than a new take every time. Cubase Pro control room keeps monitoring tidy so a headphone check does not accidentally become the only mix. These tools serve practice songs and coursework.

Record or play a short idea. Clean it in Cubase Pro key editor, mark chords on Cubase Pro chord track, and set levels in Cubase Pro mixconsole. Use Cubase Pro variaudio on one vocal phrase if you have one. Listen through Cubase Pro control room before you decide the piece is ready.

## Starting with Cubase Pro

Prerequisites: A compatible computer, headphones, and permission to run Cubase Pro.

1. **Prepare:** Save a new project in a folder you will remember.
2. **Write Notes:** Enter a simple melody in Cubase Pro key editor.
3. **Name Chords:** Add Cubase Pro chord track so the harmony is written down.
4. **Balance:** Open Cubase Pro mixconsole and set modest levels.
5. **If You Sang:** Try Cubase Pro variaudio on a short phrase only.
6. **Listen On Purpose:** Use Cubase Pro control room for the headphone check, then save.
